# MigosMC Rules 1.0.0 — дополнение ChatSorter

Создан **mlpgod** для **MigosMC**, Minecraft **1.21.11**.

## Установка и использование

1. Установите ChatSorter **1.3.4+** для Minecraft 1.21.11 и его зависимости.
2. Добавьте `migos-rules-1.0.0.jar` в `mods` рядом с ChatSorter.
3. Откройте чат и нажмите кнопку «Правила» слева сверху.
4. При первом открытии нажмите «Обновить». Не закрывайте игру до окончания загрузки. Само окно можно закрыть — загрузка продолжается в фоне.

Правила загружаются с https://forum.migosmc.net/ напрямую на компьютер пользователя. После успешной загрузки они доступны без интернета. Встроенной копии текстов в JAR нет. Кнопка «Обновить» проверяет доступные публичные разделы повторно, без пересборки мода.

Слева — темы правил; «Все разделы» включает глобальный поиск. Справа — полный текст пунктов вместе с примечаниями и наказаниями. Колесо прокручивает список под указателем. Выберите пункт и нажмите «Копировать» или «Источник». Копирование не отправляет текст в чат.

Последняя успешная загрузка сохраняется в `config/chatsorter/migos-rules.json`. При сетевой ошибке или изменении разметки форума предыдущая копия не заменяется. Дата загрузки показана сверху. Закрытые разделы и документы на других сайтах не загружаются; ссылки из правил сохраняются в тексте. Изображения представлены ссылками, их можно посмотреть на форуме через «Источник».

## Охват

Загрузчик обходит публичные разделы официальных правил и режимов, их подразделы и страницы тем. При проверке 18 октября 2026 года получены **11 тем**. Для многостраничных тем читаются сообщения автора первого поста. Обсуждения других пользователей не включаются.

## Сборка

JDK **21**, Gradle **9.2.1**: `gradle build`.
Результат: `build/libs/migos-rules-1.0.0.jar`.
Парсер HTML Jsoup включается в JAR автоматически; отдельно его устанавливать не нужно.
В `.github/workflows` предусмотрена сборка через GitHub Actions.

## Проверки

Проверены компиляция для 1.21.11, загрузка 11 тем с действующего форума, сохранение примечаний и наказаний при разделении пунктов, отказ от посторонних источников и сохранение предыдущего файла при неудачном обновлении. Полноценный запуск интерфейса в Minecraft в этой среде не выполнялся.
